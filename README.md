# Tux Script 🐧

**Tux Script** — Roblox Lua GUI Script with Linux Tux Theme.

## Features ✨
- 👻 **NoClip** — Walk through walls and objects.
- 👁️ **ESP** — Highlight all players with custom Tux colors.
- 🕊️ **Fly** — Full flight support (WASD + Space + Shift).
- 🥊 **Super Punch** — Floating action button on screen to knock nearby players away with extreme force.

## Quick Execution 🚀

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kondrakov408-sys/TuxScript/main/tux_script.lua", true))()
```
